Dashboard HTTPS memakai private CA milik panel (bukan Let's Encrypt: tidak ada domain, dan CA publik tidak boleh menerbitkan untuk IP privat). Client percaya lewat instalasi ca.crt sekali — sesudah itu semua leaf, termasuk hasil renew, dipercaya otomatis.

          

          

            
Init / Regenerasi

            

              
              
              
              
              
            

            
Init menolak bila CA sudah ada — pakai Reinit di bawah untuk ganti trust anchor. Regenerate memakai IP/Nama di atas bila diisi, kalau kosong memakai SAN yang tersimpan, lalu SAN leaf lama. Sesudah leaf berganti, dashboard tidak perlu restart (hot-swap); Apache di-restart otomatis oleh panel.

Install ca.crt di client

            
    
              
  • Windows GUI: klik ganda ca.crt → Install Certificate → Local Machine → Place in Trusted Root Certification Authorities.
    • 
              
  • Windows CLI (admin): certutil -addstore -f "Root" spanel-ca.crt
    • 
              
  • Group Policy (domain siws.local): Computer Configuration → Policies → Windows Settings → Security Settings → Public Key Policies → Trusted Root Certification Authorities → Import ca.crt. Berlaku untuk semua PC domain tanpa instal manual.
    • 
              
  • Firefox: pakai store sendiri — Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import (centang "Trust this CA to identify websites").
    • 
            

            
Yang dibagikan hanya ca.crt (publik). Kunci CA (ca.key) tidak pernah keluar dari server. Backup direktori tls ke vault/offline: restore = salin kembali + restart panel. Bila IP server berubah, pakai Regenerate leaf. Bila port 443 bentrok dengan XAMPP, ubah tls_apache_port di panel.json lalu re-apply.
